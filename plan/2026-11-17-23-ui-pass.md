# Plan: a readable, discoverable, adjustable panel and menu

Closes #23 on branch `feat/23-ui-pass`. The base is master `7b678da`
(plugin 1.1.0).

**Version:** plugin 1.2.0.

This plan is self-contained. Each step names its files, what to change, its
checks, and the traps.

## Approved decisions (from the spec)

### U1. Badge (`HerdrModel.qml`, `Panel.qml`)

- **New property:** `readonly property int needCount: blockedCount +
  doneCount`.
- **Visibility:** `badgeShown: appMark || badgeActive`. It no longer
  requires `runningCount` or `reachable`.
- **Text:**
  - `needCount` when it is above 0, with `!` appended while `appMark`
    (`2!`);
  - `!` alone when stale with nothing needed;
  - otherwise empty, drawn as a small dot in the state colour.
- **Colour:** urgent for blocked or stale, finished for done, working for
  working.
- **Size:** the bar badge does not scale with `textScale`.
- **Tooltip:** lists every non-zero part:
  - servers, agents, waiting on you, finished, working;
  - "herdr-core not reachable" while stale;
  - the classic error while unreachable.

### U2. Text size

- **The value.** `HerdrModel.textScale` becomes a writable property,
  default 1.0. The `host.textScale` fallback and `Menu.qml:64` go.
- **Steps.** `textBigger()`, `textSmaller()` and `textReset()` clamp to
  [0.8, 1.6] in steps of 0.1. Each result is rounded with
  `Math.round(v*10)/10`.
- **The file.**
  - **Path:** `$XDG_CACHE_HOME/omarchy-herdr/text-scale`, or
    `$HOME/.cache/...` when `XDG_CACHE_HOME` is unset.
  - **Reading:** a `FileView` with `watchChanges: true` and
    `onFileChanged: reload()`, like `HerdrModel.qml:1289-1296`. On load, a
    number in range is applied. Anything else leaves the value as it is.
  - **Writing:** only key presses write, with `setText`. A load never
    writes.
- **Keys outside the inputs** (bare, or with Shift only):
  - they arrive through `Card.qml` `onTextKey(t, modifiers)`;
  - `+` and `=` make text bigger, `-` smaller, `0` resets;
  - nothing happens while Alt or Meta is held.
- **Ctrl keys.** On the card and the menu window, `Shortcut` items with
  `context: Qt.WindowShortcut`:
  - `Ctrl+=`, `Ctrl++` and `Ctrl+Shift+=` make text bigger;
  - `Ctrl+-` makes it smaller;
  - `Ctrl+0` resets.
- **In the inputs** the bare keys stay literal.
- **Widths.** These multiply `textScale`, still capped by the room on
  screen:
  - `Panel.qml:103` `cardWidth` and `:104` `cardMinWidth`;
  - `Menu.qml:65` `cardWidth`.

  A pinned card's own `chosenWidth` wins.

### U3. Alpha, not darker

- **Every `Qt.darker(<x>.foreground, k)`** becomes
  `Qt.alpha(<x>.foreground, a)`, using this map:

  | k | 1.2 | 1.3 | 1.4 | 1.5 | 1.6 | 1.7 | 1.8 | 1.9 | 2.1 | 2.2 |
  |---|---|---|---|---|---|---|---|---|---|---|
  | a | .83 | .77 | .71 | .67 | .62 | .59 | .56 | .53 | .48 | .45 |

- **Contrast test.** The WCAG ratio must be at least 4.5 for `a ≥ 0.53`, and
  at least 3 for fainter values, on a dark and a light background. A failing
  value is raised, and this table is updated.

### U4. Discoverability

- **Footer**, elided at caption size, at alpha 0.48:
  - menu: `n new · a ask · i stop · x end · ± size · ? keys`;
  - bar surfaces: `o open · i stop · x end · ± size · ? keys`.
- **`?`** closes the surface, then runs `bin/herdr-menu-keys` as a detached
  `Process`.
- **The empty state:**
  - menu: "No herdr sessions. Press n to start one.";
  - bar surfaces: "No herdr sessions."
- **`x` destroys whatever the row allows:**
  - running classic session: kill;
  - stopped classic session: delete;
  - app agent: end with cascade.

  `K` does the same as `x`.

### U5. Column cursor removed

- **Symbols that go:**
  - `column`, `columnOpen`, `columnRow`, `columnDestroy`;
  - `lastColumnFor`, `moveColumn`, `cycleColumn`, `clampColumn`,
    `cursorInBody`.
- **Their uses that go:**

  | File | Lines | Use |
  |---|---|---|
  | `HerdrModel.qml` | `:696`, `:711`, `:726`, `:736`, `:1270`, `:1282` | column handling |
  | `Card.qml` | `:428`, `:606`, `:632`, `:645` | column highlights |
  | `Card.qml` | `onMoveRequested` | the dx branch |
  | `Card.qml` | `onTabRequested` | the whole handler |
- **Unchanged:** the buttons stay clickable. Enter behaves as before:
  - on an agent: land on it;
  - on a session: open it;
  - on a stopped session: start it.

### U6. Agent scroll

- **`HerdrModel.showRow(sessionIndex, agentIndex)`.** Both callers pass the
  agent index: `:351` (rebuild) and `:684` (move). `rebuild()` also calls it
  when the cursor's identity kept its key but its row index changed.
- **`Card.showRow(si, ai)`:**
  1. If the delegate is missing, call `positionViewAtIndex(si,
     ListView.Contain)`.
  2. In `Qt.callLater`, map the agent row (from the `Repeater` at
     `Card.qml:385`) into `list.contentItem`.
  3. If `top < contentY`, set `contentY = top`. If `bottom > contentY +
     height`, set `contentY = bottom - height`. A row taller than the view
     aligns its top.
  4. Clamp `contentY` to `[originY, originY + contentHeight - height]`.
- **For a session row** (`ai < 0`), the current call stays.

### U7. The `n` label

- **Behaviour is unchanged.** The label reads "New session on <host>" or
  "New space on <host>", where host is the row's host or this machine's
  hostname.
- **Layout.** The label takes its implicit width, up to half the row. The
  host never elides.
- **Placeholders:**
  - `newField`: "name, then optionally a folder";
  - prompt: "message to <title>".
- **Accessibility.** `newField`'s `Accessible.name` is the label.

### U8. Reply, layer, blink, pin focus, accessibility

- **Reply.**
  - `replyFrom()` is deleted. The reply shows the last 40 lines of the output
    in monospace, with indentation kept.
  - **Caps:** 4000 characters, cut at a line start. A single longer last line
    becomes `…` plus its last 4000 characters.
  - **Box:** at most 40 % of the card's height, and it scrolls.
- **Waiting line.** "waiting N s · Esc cancels", from a 1 s timer that runs
  only while waiting.
- **Layer.**
  - The pinned card goes to `WlrLayer.Top` (`Panel.qml:323`).
  - **D1:** the menu stays on `WlrLayer.Overlay` (`Menu.qml:354`).
- **Blink.**
  - `updateAttention()` selection is unchanged.
  - Each non-empty assignment of `attentionKey` starts an episode, which
    restarts a single-shot 60 s timer and sets `blinkExpired = false`. The
    timer sets `blinkExpired = true`.
  - `blinking` requires `!blinkExpired`.
- **Pin focus.**
  - Pinning from the keyboard sets `pinWindow.focusArmed = true` at once,
    skipping the 300 ms `armTimer`, and gives the catcher
    `forceActiveFocus()`.
  - A restored or mouse pin keeps the current path.
- **Accessibility.**
  - `Accessible.focused` is set on an agent row when the cursor is that
    agent, and on a session row only when the cursor is that session row.
  - Icon button names:
    - Open session, Kill server, Delete session;
    - End agent, Pin, Unpin.

### U9. `priority(c)`

- **What it returns:** `"blocked"`, `"done"`, `"working"` or `"idle"`.
- **Who uses it:** `noteColor`, `statusColor`, `badgeColor` and
  `noteLabel`, each keeping its own guards and palette.
- **`attentionRank`** is unchanged.

### U10. `ConfirmOverlay.qml`

  - passing `fontFamily` and `textScale`.
- **Who uses it:** Card's destroy confirm (`:695`) and Menu's busy-send
  confirm (`:498`). Each keeps its own text, actions and key handling.

## Repo traps (every step)

- **`tests/session-actions.cjs` extracts functions by name** (lines 19-34).
  Every removed or renamed function must leave that list in the same step,
  or the suite fails with "Missing function". New functions that the step's
  tests use are added to it, or extracted in the step's own test file.
- **New test files.** Each step's new tests go in its own file, so parallel
  steps never edit the same test file: `tests/ui-<area>.cjs`. Each runs with
  `node`, uses the same extraction pattern, and exits non-zero on failure.
  Step 6 wires them into CI.
- **CI runs exactly these:**
  - `bash -n` and shellcheck on `bin/herdr-sessions`, `bin/herdr-menu-keys`
    and `tests/herdr-sessions.sh`;
  - `node tests/session-actions.cjs`;
  - `bash tests/herdr-sessions.sh`.

  CI has no `qs` and no `rg`. Tests use `grep -E`.
- **Never `Keys.onPressed` on the `PanelKeyCatcher` instance.** It replaces
  the catcher's handler and loses the arrow keys (`Card.qml:686`). Use
  `onTextKey(t, modifiers)` and `Shortcut` items.
- **Imports.** QML types from the shell come in via `import qs.Commons` and
  `qs.Ui`.
  - `ConfirmOverlay.qml` sits in the plugin's root, beside `Card.qml`, so it
    is found without an import.
  - Don't remove the `Panel.qml:2`/`:5` imports unless the step-4 checks
    pass.
- **Sizes stay theme-based:** `Style.font.*` and `Style.space()`. The
  screen-height scaling stays out (`Menu.qml:58-63`).
- **No test touches the real `hc`, `herdr`, `herdr-app` or the running
  shell.**
- **Implementer agents never stage, commit, push, deploy or restart.** The
  lead commits each step.
- **#20/#22 behaviour stays:**
  - deadlines;
  - identity cursor;
  - captured prompt and new targets;
  - not-live refusals;
  - cascade-checked kill;
  - the `n` input's pending, error and read-only handling
    (`Menu.qml:167-188`, `:463`).

## Rollback

- **Before merge:** close the PR. Master is untouched.
- **After merge:**
  - `git revert -m 1 <merge>` on master;
  - point the nixarchy pin back at `7b678da` or `9dd9433`;
  - redeploy and restart the shell.

  left behind. 1.1.0 never reads it.
